# Reproducibility package — "Reproducible Evaluation of Reliability Aware Design and Fault Aware Training for Resilient Deep Neural Networks"

Everything reported in the manuscript (tables, figures, numbers in the text) is generated by the scripts in this
archive from the result files it also contains. Re-running the two experiment scripts regenerates the result files.

## Contents
| path | what |
|---|---|
| `digits_experiment.py` | Experiment 1: fully connected network on scikit-learn Digits, 6 configurations x 5 seeds, all fault-injection campaigns, latency, figures |
| `cifar_experiment.py` | Experiment 2: ResNet-8 on CIFAR-10, 5 configurations, fault-injection campaigns, round-robin latency |
| `make_diagrams.py` | Figures 1, 2 and 3 of the manuscript |
| `make_cifar_figures.py` | CIFAR-10 heatmap and training curves |
| `make_tables.py` | prints Tables IV-IX and the data behind Figures 8-9 from the JSON result files |
| `verify_results.py` | consistency checks (trial totals, shared weights, zero NaN rate, figure files) |
| `run_all.py` | runs everything in order |
| `results_digits/results_digits.json` | aggregated Digits results (mean/std/values over seeds) |
| `results_digits/per_seed/seed*.json` | raw per-seed results incl. confusion matrices, per-class metrics, training histories |
| `results_digits/predictions_seed0_*.csv` | clean prediction and probability vector of every test image (seed 0, each configuration) |
| `results_digits/fi_log_seed0.csv` | one line per fault-injection trial (configuration, campaign, fault model, site, magnitude, image, SDC, critical) |
| `results_digits/fig_*.png` | Digits figures |
| `results_cifar/results_cifar.json` | CIFAR-10 results incl. training histories, per-site rates and latency |
| `results_cifar/weights_*.weights.h5` | trained ResNet-8 checkpoints |
| `results_cifar/fig_*.png` | CIFAR-10 figures |

## Environment
Python 3.13, numpy, scikit-learn, matplotlib, seaborn, tensorflow-cpu (versions in `requirements.txt`). CPU only (2 cores were used).

## Quick start (one command)
```
python run_all.py --data /path/to/CIFAR-10-images      # runs both experiments, draws all figures, prints Tables IV-IX, runs the checks
```
`make_tables.py` prints every numeric table of the manuscript from the result files; `verify_results.py` runs the consistency checks a reviewer can repeat.

## Running step by step
```
python digits_experiment.py                       # ~2-6 min; seeds 0-4 fixed inside the script
git clone --depth 1 https://github.com/YoongiKim/CIFAR-10-images.git /path/to/CIFAR-10-images
python cifar_experiment.py --epochs 15 --data /path/to/CIFAR-10-images   # ~60 min
python make_diagrams.py; python make_cifar_figures.py
```
Seeds: Digits training seeds 0-4 (`SEEDS`), fault-injection seeds 1000+seed; CIFAR-10 seed 0 (`--seed`), fault-injection seed 1000.
Data split: Digits `train_test_split(test_size=0.2, random_state=42, stratify=y)`; CIFAR-10 standard 50k/10k split.

## Definitions
One trial = one test image with one fault injected into the output of one dense/convolutional layer.
SDC = output probability vector differs from the fault-free output; critical SDC = predicted class changes; a non-finite output counts as both.
